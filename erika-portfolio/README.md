# Portofolio Erika Hensan

Website statis multipage menggunakan HTML, CSS, dan JavaScript. Tidak membutuhkan instalasi framework.

## Menjalankan di komputer
1. Ekstrak folder.
2. Buka folder `erika-portfolio` di Visual Studio Code.
3. Pasang ekstensi **Live Server** (opsional), lalu klik kanan `index.html` > Open with Live Server. Bisa juga membuka `index.html` langsung di browser.

## Personalisasi sebelum dipublikasikan
- Ganti `assets/images/profile.jpg` dengan foto profil sendiri (nama file harus tetap `profile.jpg`).
- Letakkan CV PDF di `assets/docs/` dengan nama `CV-Erika-Hensan.pdf`.
- Tambahkan tautan GitHub/LinkedIn setelah profilnya siap.
- Periksa kembali nomor telepon, email, dan isi proyek.

## Deploy
Upload seluruh isi folder ini ke repository GitHub, lalu di Vercel pilih **Add New → Project**, import repository tersebut, biarkan Framework Preset sebagai **Other**, Build Command dan Output Directory dikosongkan, lalu Deploy.
