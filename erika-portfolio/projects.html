BH01 / WEB SYSTEM

Proyek skripsi individu · 2025–2026

Beauty Homies — Sistem Reservasi Salon Berbasis Web

Proyek ini berangkat dari masalah reservasi salon yang masih dilakukan melalui telepon, media sosial, atau datang langsung. Cara tersebut dapat menyebabkan jadwal sulit dicatat, antrean sulit diatur, dan pelanggan tidak selalu mengetahui layanan maupun jam yang tersedia.

Kontribusi saya

  • Menganalisis proses reservasi dan kebutuhan pengguna, lalu menyusun tahapan pengembangan dengan metode Waterfall.
  • Membuat Use Case Diagram beserta skenarionya, Activity Diagram, Class Diagram, dan Sequence Diagram.
  • Membangun aplikasi web menggunakan PHP, Laravel, dan MySQL dengan fitur reservasi, pemilihan layanan dan jadwal, unggah bukti pembayaran QRIS, serta riwayat reservasi.
  • Mengembangkan fitur pemilik salon untuk mengelola cabang dan layanan, verifikasi pembayaran, data booking, ulasan, serta laporan pendapatan.

Pengujian dan hasil

Black Box Testing dan UAT terhadap 70 responden dengan 10 pertanyaan menghasilkan skor 3.156 dari 3.500 atau 90,17% (kategori sangat baik).

PHP · Laravel · MySQL · Draw.io · UML · Waterfall · Black Box · UAT

ST02 / CAPSTONE

Anggota tim capstone (5 mahasiswa) · 2025

Sistem Informasi Stunting Berbasis Web — Puskesmas Gembor

Website dirancang sebagai media edukasi agar masyarakat lebih mudah memperoleh informasi mengenai penyebab, dampak, dan pencegahan stunting serta layanan terkait.

Kontribusi saya

  • Mengikuti wawancara dengan Kepala Puskesmas dan Dokter Gizi untuk menggali kebutuhan sistem.
  • Merumuskan 16 kebutuhan sistem dan mengelompokkannya menjadi Mandatory, Desirable, dan Inessential.
  • Menganalisis kebutuhan menggunakan aspek TOE (Technical, Operational, Economic).
  • Menyusun Use Case Diagram, 11 Activity Diagram, dan Class Diagram.

Ruang lingkup rancangan meliputi informasi umum, edukasi ibu hamil, video edukasi, pencegahan dan dampak stunting, peta wilayah, data dan grafik stunting, kontak dokter, forum, donasi, serta dashboard admin.

Waterfall · Requirement Elicitation · UML · Laravel
